# `app/` — the ShotLedger app

React Native + Expo (SDK 57) + TypeScript, file-based routing with Expo
Router. Local-first: `expo-sqlite` with Drizzle ORM is the source of truth,
and the app works fully with no account and no network.

`PRODUCT.md` in this directory is the product definition: users,
positioning, operating context, principles. Read it before changing a
screen.

## Layout

| Path               | What lives there                                                                                                                                                                                                                        |
| ------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `src/app/`         | Routes. `(tabs)/` holds the five tabs (Home, Statistics, Firearms, Tools, Settings); the rest are stacked screens such as `session/`, `firearms/`, `vault/`, `timer`. `dev/` is a `__DEV__`-only demo-data and component-gallery route. |
| `src/features/`    | Screen-level logic grouped by feature (session, regulations, photo scoring, timer, …).                                                                                                                                                  |
| `src/components/`  | Shared UI primitives.                                                                                                                                                                                                                   |
| `src/db/`          | Drizzle schema, migrations (`drizzle/`), queries and the SQLite client. `client.web.ts` is the null client for the web preview.                                                                                                         |
| `src/i18n/`        | `en.json` and `sv.json`. Every user-visible string goes through them; the key sets must match (gated).                                                                                                                                  |
| `src/platform/`    | Wrappers around anything platform-specific, so no screen branches on Android versus iOS itself.                                                                                                                                         |
| `src/constants/`   | Generated open-source license list and the hand-maintained native-license list shown on the About screen.                                                                                                                               |
| `e2e/`             | Maestro flows (`maestro test e2e/<flow>.yaml`).                                                                                                                                                                                         |
| `android/`, `ios/` | Generated by `expo prebuild`; gitignored.                                                                                                                                                                                               |

Domain logic does not live here. Scoring, disciplines, regulations,
compliance and exports are in [`../shared`](../shared/README.md) so the
backend and tests share them.

## Running it

```bash
pnpm exec expo start --web --port 8081   # web preview: fastest way to iterate on UI
pnpm exec expo run:android               # dev build onto a running emulator
```

The emulator, ADB driving, screenshots, the demo-data deep link
(`app://dev`), standalone release builds and the many gotchas found along
the way are written up in the root `CLAUDE.md`, "Agentic loop". The web
preview has no SQLite, so anything that touches the database needs a
device or emulator.

## Conventions that are checked

- UI strings via i18n from the first screen. English labels Title Case,
  English body copy sentence case, Swedish sentence case throughout.
- No Android-only native modules; platform quirks go behind
  `src/platform/`.
- Schema changes need a Drizzle migration. Adding a dependency means
  regenerating `src/constants/licenses.json` (`pnpm licenses:generate` at
  the repo root); a native dependency is hand-added to
  `src/constants/native-licenses.ts`.
- UI changes are verified by driving the running app and ship with a
  screenshot, and the user manual under `docs/manual/` is updated in the
  same pull request.
