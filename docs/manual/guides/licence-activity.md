# Licence activity

Swedish firearm licence renewal asks you to document range activity. The app
keeps that record from the sessions you are already logging.

**Settings → Compliance → Sweden (FAP 551-3)** turns it on. Left at **None**,
none of this appears — which is the right state outside Sweden.

## The barometer

Once on, the app shows where you stand: activities inside the rolling window,
and how many the profile expects.

!!! danger "The numbers are unverified defaults"

    The window length and required activity count shipped as placeholders and
    are marked unverified in the app itself. They have not been confirmed
    against FAP 551-3's actual text.

    **Do not rely on this for a renewal decision.** Check the current
    requirement with your club or the police, and treat the barometer as a
    convenience for counting sessions you already logged — not as an authority
    on what is required.

    This is deliberate: the project's rules forbid presenting an unconfirmed
    regulatory value as fact, and shipping a plausible-looking number would be
    worse than shipping an honest warning.

## What counts

Sessions you have logged, in the rolling window. Because the record is built
from sessions rather than entered separately, it is only as complete as your
logging — a range visit you did not log is not in it.

## Getting it out

**Settings → Backup** exports everything. A club-log PDF export also exists for
the summary a förening might ask for.

!!! note

    The PDF layout has not been checked against a real föreningsintyg. It was
    built to the specification rather than against a sample, so confirm it is
    acceptable before relying on it for a submission.
