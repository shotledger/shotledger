# Reglementen

**Inställningar → Reglementen.** Vilka regelverk du tävlar under.

Svenska pistolskyttar tillhör inte alla samma förbund, och många tillhör två
samtidigt. Det du slår på här avgör vilka grenar, vapengrupper och
tävlingsklasser du erbjuds när du skapar ett pass.

Slår du på fler än ett frågar formuläret för nytt pass vilket du skjuter under
innan det frågar efter gren — en klubbs precisionskväll och en SvSF-tävling i
luftpistol har inga grenar gemensamt, och en sammanslagen lista skulle tvinga
dig att leta igenom det andra förbundets för att hitta din. Fri träning mot
ringad tavla tillhör inget förbund och finns därför kvar oavsett vilket
reglemente du väljer.

## Vad som finns

| Reglemente                                         | Vad det omfattar                                                                                                                                           |
| -------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **SPSF** — Svenska Pistolskytteförbundet           | Precision, militär snabbmatch, magnumprecision och vapengrupperna (en _weapon groups_) A/B/C/R och M1–M9. På som standard.                                 |
| **ISSF** — International Shooting Sport Federation | De internationella grenarna: luftpistol, fripistol, sportpistol, standardpistol, snabbpistol och grovpistol.                                               |
| **SvSF** — Svenska Skyttesportförbundet            | Svensk nationell tävling: ISSF:s grenar, plus SvSF:s egna — snabbluftpistol samt de öppna klasser, juniorklasser och herrklasser som skjuts vid SM och DM. |

### Grenar per reglemente

Vad grenväljaren erbjuder för varje brytare, med de namn appen använder. En
gren som står under SvSF men definieras av ISSF är samma definition, nådd via
SvSF — den läggs aldrig in två gånger.

| Gren                | SPSF | ISSF | SvSF | Definieras av | Klassväljare                                   |
| ------------------- | ---- | ---- | ---- | ------------- | ---------------------------------------------- |
| Precision           | ✓    |      |      | SPSF          | Vapengrupp och klass                           |
| Militär snabbmatch  | ✓    |      |      | SPSF          | Vapengrupp och klass                           |
| Magnumprecision     | ✓    |      |      | SPSF          | Endast vapengrupp — ingen klass                |
| Nationell helmatch  | ✓    |      |      | SPSF          | Vapengrupp och klass                           |
| Figurskjutning      | ✓    |      |      | SPSF          | Vapengrupp och klass                           |
| Luftpistol          |      | ✓    | ✓    | ISSF          | Tävlingsklass                                  |
| Sportpistol         |      | ✓    | ✓    | ISSF          | Tävlingsklass (SvSF lägger till Herr)          |
| Standardpistol      |      | ✓    | ✓    | ISSF          | Tävlingsklass (SvSF lägger till Junior)        |
| Snabbpistol         |      | ✓    | ✓    | ISSF          | Tävlingsklass (SvSF lägger till Öppen, Junior) |
| Grovpistol          |      | ✓    | ✓    | ISSF          | Tävlingsklass (SvSF lägger till Öppen)         |
| Fripistol           |      | ✓    | ✓    | ISSF          | Tävlingsklass (SvSF lägger till Öppen, Junior) |
| Snabbluftpistol     |      |      | ✓    | SvSF          | Tävlingsklass (Öppen, Junior)                  |
| Träning (ringtavla) | ✓    | ✓    | ✓    | ingen         | ingen — även med allt avslaget                 |

## SvSF tar med sig ISSF

SvSF tävlar enligt **ISSF:s regelbok** — förbundet ger ut svenska översättningar
av ISSF:s kapitel 6, 7 och 8, och det är de som styr nationella tävlingar.

Att slå på SvSF sätter alltså ISSF:s grenar i spel utan att du slår på ISSF
separat. Skärmen Reglementen säger det på ISSF-raden, i stället för att lämna
dig undrande över varför grenar dök upp från en brytare som fortfarande är av.

De är inte samma sak, och det är därför båda finns:

- SvSF:s översättningar styr **nationella** tävlingar; ISSF:s egen text styr
  **internationella**.
- SvSF lägger till sådant ISSF inte har något begrepp för — egna allmänna
  bestämmelser, sin fastställda lista över SM- och DM-grenar, sina egna
  skyttemärken.
- SvSF skjuter mästerskapsklasser som ISSF:s grenlista saknar: en öppen klass
  där ISSF delar på herrar och damer, en gemensam juniorklass, och en
  herrklass i sportpistol.

## Vad SvSF lägger till

Utöver ISSF:s grenar ger SvSF påslaget dig:

- **Grovpistol**, under sitt ISSF-namn **25 m Centre Fire Pistol**. Det är
  samma skjutprogram som sportpistol, skjutet med grovkalibrigt vapen, och
  ligger därför i ISSF-listan i stället för att definieras två gånger.
- **Snabbluftpistol**, SvSF:s egen 10 m-gren: 60 skott i två omgångar om
  2 × 10 s, 2 × 8 s och 2 × 6 s femskottsserier, på sin egen 10 m-tavla.
- **Mästerskapsklasser** som skjuts vid SM och DM, som extra val i en
  tävlings grenväljare:

| Gren                | SvSF lägger till                    |
| ------------------- | ----------------------------------- |
| 25 m sportpistol    | Herrar                              |
| 25 m standardpistol | Junior (herrar och damer gemensamt) |
| 25 m snabbpistol    | Öppen, junior                       |
| 50 m pistol         | Öppen, junior                       |
| Grovpistol          | Öppen                               |
| Snabbluftpistol     | Öppen, junior                       |

Luftpistol får inget extra: herr-, dam- och juniorgrenarna är redan ISSF:s.
Junior i de här klasserna är den som är upp till och med det år hen fyller 21
i ISSF-grenarna, och 20 i snabbluftpistol — appen förväljer efter det som
gäller.

!!! note "Finns ännu inte i appen"

    Falling target (räknas träff eller bom, vilket appens ringräkning inte
    täcker), finaler, mixade lag och andra lagtävlingar, veteran-, ungdoms-
    och stödhandsklasserna samt SvSF:s skyttemärken. Appen är byggd för att
    rymma dem; reglerna är inte inlagda, och projektet gissar sig inte till
    regelverksdetaljer.

## Vad som ändras när du slår på ett

Bara det du **erbjuds** när du skapar ett pass: dess grenar, de vapengrupper
som grenarna tillåter, och — för ISSF och SvSF — tävlingsklasserna. Med fler
än ett reglemente påslaget frågar formuläret först vilket (se ovan); med ett
säger grenen du väljer det.

Pass du redan loggat rörs inte. Att slå av ett reglemente döljer eller ändrar
ingenting du skjutit under det — ett pass loggat i en SvSF-klass behåller
klassen, och kan fortfarande redigeras, efter att SvSF slagits av.

## Med allt avslaget

Du kan fortfarande logga träningspass mot ringad tavla. Det tillhör inget
förbund och överlever därför varje filter, och appen förblir användbar utanför
varje förbund den råkar känna till.
