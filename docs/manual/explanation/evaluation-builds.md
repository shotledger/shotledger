# Evaluation builds

An evaluation build is a copy of ShotLedger handed out for testing before
the app is in Google Play. It is installed from an APK file rather than from
the store, and it stops working on a date set when it was built, normally 30 days later. Settings →
About shows that date.

An evaluation build is yours to test, not to pass on: it is handed out for
personal testing only, and no other license comes with it.

## When it stops

From that date on, the app opens on an **Evaluation Build Expired** screen
instead of your logbook. Nothing is deleted: your sessions, firearms and
settings stay on the phone, and the screen keeps **Export Sessions** so you
can take a copy with you. Ask whoever gave you the build for a new one;
installed over the old one, it opens on the same data.

A build from Google Play never expires.

## Why setting the clock back does not help

The app remembers the latest date it has seen and never counts backwards from
it. Setting the phone's clock back neither reopens an expired build nor gives
an active one more time. All it does is put the wrong date on the sessions you
log.
