# ShotLedger

Target Shooting Log & Scoring — a free, donation-funded app for target
shooters: training and competition logging, camera-based target scoring,
and Swedish license compliance (FAP 551-3). Offline-first; no account
required.

See [`app/PRODUCT.md`](app/PRODUCT.md) for what this is and why,
[`docs/implementation-plan.md`](docs/implementation-plan.md) for the
execution spec, [`docs/adr/`](docs/adr/) for architecture decisions, and
issue [#138](https://github.com/jimisola/shotledger/issues/138) for
what's outstanding.
